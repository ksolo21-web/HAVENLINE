# Independent crown spacing geometry check

All exact upstream manifest/member hashes and source GLB bytes were verified. Decoded the two GLB primitives independently and evaluated strict crossings by solving the two-plane intersection line and clipping it against all six oriented edge halfspaces; the worker method instead intersects signed plane sections. Independent results agree for every count, indexed strongest pair, segment length and no-crossing positive control. The exact numerical fixture uses Godot X/Y spacing at Z=0 (vertical Y); glTF is Y-up, whereas Blender's Z-up transform interchanges the labels for vertical/depth. No engine or renderer run.

The 35 mm layout is invalid for these parallel full-size models: 1593/746 strict pairs on actual fixture X/Y, and 789 for additional glTF Z-only diagnostic. X/Y strongest shared segments: 56.755/41.842 mm, not penetration depth. The 1 mm clear axis-projected translation construction is sufficient, not minimum. Four 2-by-2 placements are approximately 284 × 206 × 209 mm and exceed the nominal carry mount box height; at most two such axis-separated copies fit in that technical whole-bundle box even if empty. The 50 × 50 mm lip is unbound support test geometry, whereas the crown's aligned bounding footprint is 11.782 times the patch area. Area ratio cannot prove contact, stability or failure of an overhanging/rotated object on a larger board. No animation, role, item-scale, carry capacity, perf, or gameplay approval; small real-anchor clearance witness is next, not 52 actual mesh placements.
