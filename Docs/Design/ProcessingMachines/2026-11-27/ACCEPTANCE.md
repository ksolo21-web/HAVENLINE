# Resource and processing-machine render completion

## Scope
Finish the existing nine industrial resource illustrated eight-view sheets and produce six missing processing-machine concept turnarounds for the current Havenline resource economy. Preserve all existing resources, selected machines, rejected attempts, sources and task definitions. Static raster concepts are the requested deliverable; meshes, rigging, animation and runtime integration remain separate.

## Requirements
- R1: All nine selected industrial resource images match the independently reviewed exact hashes; preserve all attempts and reviews.
- R2: Six distinct new producers: coal_smelter, hand_metal_bench, steel_forge, assembly_bench, manual_oil_pump, coal_refinery.
- R3: Each new sheet illustrates eight readable azimuth views (front, front-right, right, rear-right, rear, rear-left, left, front-left) of one consistent design with no missing rear.
- R4: Match rounded blue/orange Havenline industrial language, warm timber where appropriate, snow at fixed exterior ledges, navy presentation. No gritty photoreal substitute, arbitrary extra resource identity or generic factory placeholder.
- R5: Every design has visibly plausible authored input/output interfaces and a mapped selected recipe. Solid-material feed, auxiliary coal and oil/fuel transfer stay distinguishable; manual service remains possible.
- R6: Preserve existing sawmill/quarry/cooker/wheat art through exact references. Write a complete bounded chain mapping, animation intent and bootstrap/recovery dependencies without declaring those implemented.
- R7: Separate critic inspects full sheets and meaningful closeups; reports actual coverage, exact hashes and honest dimension scores. Target10, inherited exact10 visual gates and zero unresolved mandatory defects for scoped art selection; missing evidence stays blocked.
- R8: Freeze selected files, previews, prompts, rejected revisions, provenance and review records. Commit and publish on an isolated art branch; verify remote commit paths/blob identities. No workflow, main-branch, gameplay or active task ownership changes.
