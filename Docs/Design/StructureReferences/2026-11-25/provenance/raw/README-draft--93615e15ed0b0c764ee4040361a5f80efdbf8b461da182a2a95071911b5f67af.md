# Havenline — fence, gates and customer counters

This batch extends the approved polished stylized 3D presentation to three sourced structures: the rope-bound snow-capped timber fence, the paired timber camp gates, and the customer-facing timber service counter. The planned delivery contains nine selected static reference sheets: eight horizontal rotation views for each structure, plus construction details, gate states, and repeated customer-counter placements.

## Source and design decisions

The original supplied fence and gate image files were recovered without alteration and verified against their recorded SHA-256 values. They control the structures' identity. The latest character reference controls the light-gray studio presentation, lighting and material finish. Character pose and finger rules do not apply to these structures.

The fence is shown as an eight-log representative module of the continuous original fence. It retains dense rounded timber, two front rails, crossed cream rope lashings and pointed snow crowns. The paired gate retains its framed plank leaves, diagonal bracing and stout rope-bound outer posts. Concealed construction and modest hinges/latch are clarified for the reference sheets; these are not measured engineering drawings.

The source gameplay shows two repeated customer counters and another roadside placement of the same timber/register construction. This batch therefore provides one canonical customer-counter design and a repeated-placement view. The blue-and-metal processing bench remains a distinct internal production asset.

## Scope of approval

These are static raster reference renders. Visual review covers identifiable construction, material/style continuity, meaningful views, gate open/closed arrangements, and customer/staff-side access. It does not prove native geometry, rigging, animation, navigation, physics or collision behavior.

The earlier requirement for at least two distinct usable bidirectional camp openings remains a requirement for camp layout/runtime work. It is preserved and is not claimed as tested or fulfilled by this isolated gate reference batch. No game scene, model, runtime, workflow or active development branch is changed here.
