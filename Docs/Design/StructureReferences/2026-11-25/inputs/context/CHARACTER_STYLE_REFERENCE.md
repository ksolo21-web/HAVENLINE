# Havenline — character style reference

## User direction

On November 24, 2026, Kaleb requested: “360 renders of characters 1-4, this style i want for all.” He supplied the image preserved as [user-style-reference.jpg](inputs/user-style-reference.jpg). This is the common visual reference for this character batch and subsequent character render work following that direction. The current batch covers Characters 1–4.

## Shared visual standard

Use the supplied polished stylized 3D appearance: mature readable body proportions, clean facial forms, natural individual fingers, detailed blue/orange winter clothing, cream shearling, leather gloves and boots, and soft studio lighting on a light neutral gray backdrop. Character 1 should match the supplied face, glasses, short curls, beard, garment shapes and proportions. His supplied design has no belt, pouch, backpack or harness.

Preserve the separate identities of Characters 2–4 while transferring this rendering style. Character 2 retains her straight side-swept bob, glasses, raised hood and blue bedroll. Character 3 retains her center-parted curls, burgundy inner layer, cream vest, open coat and tall framed pack. Character 4 retains her headband, hoop earrings, fingerless gloves, harness and brown bedroll. Their exact original image sources and hashes are recorded in the input provenance.

## Turnaround requirements

Each character has two four-view sheets: cardinal views at 0°, 90°, 180°, 270°, and diagonal views at 45°, 135°, 225°, 315°. Keep one consistent horizontal T-pose, full-body framing, true opposed profiles, head and torso aligned to the camera orientation, stable anatomical side placement of equipment, and coherent hands and feet. Normal foreshortening and occlusion are acceptable; detached, duplicated or incorrectly exposed parts are not.

Kaleb added: “we need to be able to see all the fingers too. Preferably spread for rigging”. All current body sheets therefore use open hands with four naturally separated fingers and one distinct thumb. Palms face forward relative to the torso, with thumbs generally upward; hands rotate with the body. Preserve the character's full or fingerless gloves and original cuff design. Front views show the palms and rear views show the backs. Profiles retain the same pose with natural foreshortening.

Each character also has a four-panel hand-reference sheet: left palm, right palm, left back and right back. These closeups show the whole wrist and cuff, all five connected digits, clear gaps, and correct left/right anatomy. Fingers point upward in these closeups. Palmar and dorsal surfaces must remain distinct. Character 4 retains fingerless gloves and exposed fingertips, with nails visible only from the back. The complete selected batch is eight body sheets plus four hand sheets: 32 body angles and 16 hand closeups.

The original requirements and pre-revision renders remain as historical records. Current acceptance is governed by requirements-v2.json, which reopens the hand checks while preserving the approved identities, clothing and equipment.

The requested 2048×2048 size is an image-generation request, not an assertion of the tool’s delivered resolution. Record each actual native PNG size and retain the untouched generated bytes. Review readability at actual resolution.
