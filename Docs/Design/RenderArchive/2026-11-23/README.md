# Havenline renders — 23 November 2026

This folder preserves the rendered images produced for the resource, plot, equipment, survivor, NPC and animal-companion work on this date.

The earlier reviewed resource and plot sheets remain in [ResourceTurnarounds](../../ResourceTurnarounds/). This archive adds the recovered equipment/character concepts and their initial, rejected and repair versions. Actual PNG bytes are stored directly in GitHub.

- `candidates/`: generated concept sheets and revisions, grouped by category.
- `native-reference/`: reference views rendered from the existing character models during this work.
- `image-index.json`: original filenames, committed paths, byte counts and exact image hashes. Identical bytes share Git objects.
- `prior-art-hashes.json`: the protected earlier 330-file resource/plot baseline.

Archiving a render does not approve it. The selected reviewed-image list is separate from these candidate and revision archives. This static render collection does not certify meshes, rigs, animations or runtime integration.

The intended new roster has 69 source-bound slots: 52 equipment/tool/defense sheets and 17 human/companion sheets. A complete named handheld-combat weapon roster has not yet been established from the supplied sources. Open rendering and review defects remain open until resolved by exact-image review.
