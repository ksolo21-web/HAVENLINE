# Authored thirteen-cylinder construction guide

**AUTHORING_GUIDE_NOT_SOURCE_EVIDENCE.** This directory preserves a newly drawn structural diagram used to help imagegen repair the rear roller array in conveyor sheet06. It contains thirteen explicitly constructed cylindrical rollers and twelve gaps. These are arbitrary guide units, not measured game dimensions.

The guide does not establish the roller count in the source video and is not recovered machine geometry, a runtime mesh, selected artwork, or an independent approval. The finished four-view candidate was produced by imagegen; guide pixels were not pasted into it.

The request and receipt files are preserved unchanged, including their original scratch paths. Repository aliases in the custody file provide the resumable lookup.

The clarified R7b request produced the candidate using the same two references and the same required geometry. Native and exact nearest-neighbor inspection crops are evidence only. Independent certification of the actual final roller count remains separate.
