# HAVENLINE — Aurora Light and Dark

**Aurora is the owner's selected UI family.** These matching Light and Dark refinements remove the visible joystick while retaining the sparse floating HUD, minimap expansion control, Camp/Build actions and recognizable daylight winter camp.

The [gallery](GALLERY.md) shows both proposed themes, each with illustrative landscape and portrait views. The two new images remain pending owner artwork review. They do not demonstrate a functioning touch-anywhere system or certify device responsiveness.

Read [the exact requirements](requirements.json) and [owner decision/input notes](DECISIONS_AND_INPUT.md) for the confirmed direction and separately labeled implementation proposals. [Provenance](provenance.json), [actual critic reports](reviews/) and [checkpoint](checkpoint.json) preserve source identities and scope. Requirements contain the saved planning milestones; the checkpoint records the reviewed archive stage.

Both original generated PNGs and their prompts are retained unchanged. The [selected Aurora r2 source](https://github.com/ksolo21-web/HAVENLINE/blob/b02eb61d256fb12c9e2abae8857a2fbb089300f4/Docs/Design/UIConcepts/2026-11-28/modern-directions-02/generated/aurora-r2.png) and all earlier options, joysticks, revisions and evidence remain untouched historical records. This package adds only its own dated directory; it changes no game runtime or workflows.
