# HAVENLINE — modern UI candidate concepts 02

Three additional static interface directions for comparison: **Aurora**, **Ember** and **Alpine**. Each board shows illustrative landscape and portrait compositions, an expandable-minimap affordance, simple movement/context controls and the same recognizable winter-camp language.

**No direction has been selected by the owner. These are visual concepts, not an implemented or approved game interface.** Device rotation, fold transitions, real safe insets, touch targets and map-opening behavior remain untested. The illustrative landscape and portrait frames do not prove same-phone responsiveness.

## Compare the candidates

See the [gallery](GALLERY.md): Aurora r2, Ember r2 and Alpine r1 are the current comparison set. All five generated originals are retained under `generated/`, including the earlier Aurora r1 and Ember r1 versions that required refinement.

| Direction | Main distinction |
|---|---|
| Aurora | Light, sparse floating HUD with restrained cyan and warm accents. |
| Ember | Dark command rail in landscape, compact dock in portrait, warm primary action. |
| Alpine | Calm porcelain/sage treatment with grouped status and clear destination guidance. |
