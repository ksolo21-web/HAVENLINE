2. Record exact commit, image path, Git blob and SHA-256 in the task packet, together with the corresponding model/texture/rig and runtime scene.

4. Preserve the owner design and Character 1 scale. Resolve reference-video versus owner-art conflicts explicitly; do not introduce stand-ins or reimagine an approved design.
