# Havenline snow truck and garage — acceptance contract

Version 1 • 2026-11-27 • Owner: Kaleb • Integration owner: Alfred (/root)

## Authorized scope

Continue the existing gameplay-gap work without overwriting active publication or changing existing task identities. Add the requested truck and garage design, matching Havenline's selected chunky stylized blue/orange/wood/snow visual language. Preserve all original plans and reference evidence. New work remains isolated until its proper integration gate passes.

## User requirements (mandatory)

| ID | Requirement | Required evidence |
|---|---|---|
| VG01 | Player drives a snow truck. | Design contract; later real input/drive runtime evidence. |
| VG02 | Horizontal blades mounted low on the truck attack enemies, fell trees and break rocks/mining nodes. | Multi-angle concept sheets clearly show horizontal blade plane; typed target rules; later animated contact evidence. |
| VG03 | Truck purchase requires a completed garage and an in-camp purchase plot; cost is substantial and uses relevant resources the player can obtain. | Prerequisite and dynamic quote acceptance cases; numeric balance explicitly pending playtest. |
| VG04 | Garage door replaces a section of camp fence. | Front/rear/both-side and open-door context renders; boundary/navigation rules; later measured scene fit. |

| VG06 | Truck has HP. Destruction outside camp loses every resource still in its inventory. | Death/custody edge-case checks and explicit exception to persistent-salvage default. |
| VG07 | Parking fully inside the garage transfers truck resources to the storage house. | Docking/transfer/save/duplicate event checks; unavailable storage retains cargo. |
| VG08 | 360-degree views of truck and garage. | Generated turnaround concept sheets with front/rear/left/right plus useful oblique/detail/use states. These are concept art, not a 3D asset or animation validation. |
| VG09 | Existing approved scope remains intact. | No main/runtime changes, unchanged authentic task IDs/dependencies/statuses and source checkpoint. |

## Closure work

Define safe docking, garage door obstruction, interior/camp circulation, finite/full/destroyed storage handling, cargo-loss boundaries, driver exit, destruction/rebuy, no softlock replacement resources, and animation acceptance. Clearly separate explicit user rules from authored recommendations and pending balance choices. Preserve two distinct usable bidirectional pedestrian camp openings; garage cannot silently remove those.
