## What 9.9 matching means

| Rule | Required result |
|---|---|
| Ordinary current critic floor | Every applicable mandatory dimension ≥9.5, unrounded; this alone does not earn the requested match label. |
| Requested reference-match attainment | Every applicable matched-reference dimension ≥9.9, unrounded, with complete source-bound evidence and no unresolved mandatory defect. No averaged score. |
| Existing stronger visual lock | C1 `reference_fidelity` and `visual_language` equal 10.0 exactly where applicable; zero style defects. |
| Unknown or untested area | Unverified/null; never scored as a pass. |
| Static image or archive receipt | Design/custody evidence only; cannot pass a mesh, rig, motion, gameplay, audio or device requirement. |
| Historical accepted source | Preserved as history. Changed artifacts and owner-reopened findings need affected revalidation. |

Review dimensions are reference composition/scale, silhouette/material language, physical action and object contact, carrying/transfer readability, world/upgrade response, service/production topology, motion/feedback and UI readability where applicable. Audio uses its own listening criteria because the current reference research did not hear a usable soundtrack. Independent reviewers must inspect the actual result against the source, record raw findings and score the lowest required dimension. A desired number is not evidence and cannot justify unchanged rescoring.
