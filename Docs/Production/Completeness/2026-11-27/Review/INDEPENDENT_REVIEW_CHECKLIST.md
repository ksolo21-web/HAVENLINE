## Scope and acceptance

The current request explicitly requires all seven pets to attack and a coherent review of known gaps across the existing game. The deliverable is a source-grounded forward plan and gap register. A planning pass does not prove gameplay implementation, balance, animations, audio, hardware performance, production services or release readiness. No finite audit can certify that all unknown future defects have been eliminated.

All checks below are mandatory for the planning artifact. Target 10/10; any failed or untested mandatory check blocks approval. A score of at least 9.9 is required for this source-sensitive artifact. Runtime acceptance retains all existing mandatory per-dimension 9.9 and stronger exact-10 reference requirements; no averaging or altered thresholds.

## Review sequence

1. Read authoritative current source, preserved task/reference requirements and prior gameplay-depth package; record findings without editing the candidate.
2. Inspect actual new contract, species/economy detail, whole-game crosswalk and navigation changes.
3. Run bounded read-only checks and targeted negative probes in memory or disposable copies. Do not directly run canonical task-packet writers.
4. Report defects with source evidence; root/builders repair. Re-read changed actual output and retest the concrete risk.
5. Bind the final honest planning verdict to the final freeze; preserve failed results. Runtime and publication approvals remain separate.
