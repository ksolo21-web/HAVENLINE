# Level 1 at native 4K

The gameplay camera rendered each frame at **3840 × 2160** on Ultra, with a 3D scale of 1.0. The first pair reopens a copy of the first paid camp checkpoint from the recorded touch playthrough. The second frame uses the maximum 2× pinch zoom. The HUD, player and terrain are rendered together.
