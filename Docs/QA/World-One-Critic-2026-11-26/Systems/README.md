## Restart reproduction

The probe loads the normal scene using private disposable native XDG profiles. It inflicts a lethal hit outside unpaid camp, advances 63 physics ticks, saves, and tries a one-point hit before and immediately after a process restart. Tests inject only the hit and controlled simulation time. The full route above independently drives ordinary touch input. [Reproduction script](combat_restart.gd)
