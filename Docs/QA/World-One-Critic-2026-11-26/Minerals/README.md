# Metal ore and slate

The revised stone shapes were compared with Alfred’s eight-angle turnarounds. The mean silhouette match across the five native camera views available for both builds improved from **0.888 to 0.939 for metal** and **0.787 to 0.856 for slate**. Each image was independently centered, grounded and normalized to the same width. A value of 1 means the two measured foreground masks cover exactly the same pixels.
