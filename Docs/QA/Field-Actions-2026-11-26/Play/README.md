# Play the field actions update

Open the private page on your Android phone, tap **Download Android APK**, then open the file and choose **Update**. The download uses the existing trial’s package ID and signing certificate. Keep the existing app installed to carry your camp forward. [Private Android download](https://havenline-level1-android-playtest.ksolo21.chatgpt.site)

| Action | Phone control |
| --- | --- |
| Run and stop | Drag on open ground to run. Lift to stop. |
| Gather and fight | Move within reach outside the fence. The rotating axe automatically hits targets along its length. |
| Use either gate | Run toward the opening. The gate opens automatically in either direction. |
| Buy a plot | Gather the displayed materials and stand on the marker. Each bundle contributes ten units. The marker remembers what you contributed between visits. |
| Unlock the owl | Establish the camp, then fund the survivor plot. Outdoors the owl engages nearby wolves automatically. |
| Zoom | Pinch between the normal gameplay view and 2×. |
| Change graphics | Tap the graphics control to switch between Standard and Ultra. |

Partly paid plots retain their former prices after an update. New prices apply to untouched plots. QA used disposable profiles, including one with a partly funded camp and one with all eight camp purchases.
