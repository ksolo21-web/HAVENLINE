# Havenline pine canopy repair

Codex revised the three bank pine variants in `0f64bb2775e39c94df9d36e91019b5418ae6cc0f`. The original Havenline crowns now have recessed branch shoulders and broader, uneven snow faces above the darker lower tiers. The bake reuses the original trunks, textures and UVs and preserves the tree dimensions used for fall clearance and harvesting. [Asset change](https://github.com/ksolo21-web/HAVENLINE/commit/0f64bb2775e39c94df9d36e91019b5418ae6cc0f)

The approach activated the same asset as a harvestable tree. All four regression suites passed for forest clearance and regrowth, worker harvesting, camera composition, and truck contact.
