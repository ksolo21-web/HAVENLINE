# Havenline conveyor and resource reference readback

This readback compares the new static artwork to the previous T06 gameplay candidate. The latest artwork is published and inspected. The current trial still uses its previously verified T05 wide receiver, fixed old dock art, and context-specific cargo sizing. The dock and material references below are the new comparison baseline. This is a source and visual readback using existing native captures.
