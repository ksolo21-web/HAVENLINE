# Play the Level 1 reference update

Open the private playtest page on your Android phone, tap **Download Android APK**, then open the file and choose **Update**. The trial uses the same Android package and signing certificate as the previous build. Keeping the app installed carries your camp forward. [Private playtest page](https://havenline-level1-android-playtest.ksolo21.chatgpt.site)

| Action | Phone control |
| --- | --- |
| Run | Drag on open ground in the direction you want to go. Even a short intentional drag starts a run. Release to stop. |
| Gather or fight | Run outside the camp. The orbiting tool attacks automatically once a target comes within reach. |
| Go through a gate | Approach from either side. The doors open automatically. |
| Deposit resources | Run to the **middle of the starter storehouse doorway** or go inside. Wood and meat stream into their marked bays. The stock count updates as each delivery lands. |
| Upgrade the storehouse | Stop on the **gold arrow at the right-hand edge** of the entrance apron. The HUD shows the upgrade and remaining cost. |
| Feed equipment | Bring meat to the cooker, wood to the saw, or stone to the drill. Approach the intake. Once the load lands, you can run away while the machine processes it. |
| Pay for a plot | Stand on its marked pad with the required materials available. Watch the bundles fly and the price fall. |
| See the survivor and owl | Fund the survivor plot and approach the stranded worker. Follow the forester to see chopping and carrying. The equipped owl accompanies the player outside camp. |
| Inspect at pinch zoom | Pinch on the play area to change zoom. The gameplay camera keeps its angle. |
