# Rescued forester source

The owner’s eight-view sheet identifies the winter parka, red scarf, rounded fur, curled hair, beard, satchel and cross-back strap. Meshy generated the underlying 3D model from the aligned 45-degree front-right view. The source GLB contains the original 29,240-triangle result and 2048 by 2048 painted color map. The native game adds the coat-fitted rear strap, individually skinned gloves and toes, and a 2048 by 2048 surface map. The runtime model has 29,888 triangles and eighteen skeletal joints.

One completed Meshy generation used 15 credits. Its task ID is `01a21a44-300a-75e3-a046-d5cf5ebd628e`. The full generation and game-asset hashes are in [the provenance record](Forester-provenance.json).
