# Havenline Build 16 · Snow truck purchase

[Download Build 16 for Android](https://havenline-level1-android-playtest.ksolo21.chatgpt.site/Build-16.apk). Install as an update to keep your existing camp.

1. In an expanded camp, complete the garage for 180 wood and 120 stone.
2. Open **Build → Buy snow truck** to mark the truck’s own plot.
3. Walk to that plot. A standard camp uses 240 wood and 160 stone. A camp that installed both conveyor upgrades before building the garage uses 300 wood and 200 stone. Payment can draw from the pack and the storehouse.
4. Walk into the camp-side garage entrance and tap **Drive**.

Build 15 still required 240 metal ore and 120 coal after paying its wood and stone charges. The seeded deposits were beyond the starting resource area, and the long quote could run past the edge of the mobile menu. Build 16 uses available raw materials and puts the vehicle first in the Build list. Rows wrap inside the purchase panel.

Returning camps receive all previous partial truck payments in the pack on upgrade. Completed trucks keep their location, cargo, health and historical receipt. Replacements use the current playtest price.

The independent native purchase replay used the fixed gameplay camera on a 460 × 760 window. It paid for both plots entirely from storage and mounted the truck after using the visible guide and Drive controls. The same route passed from the signed Android resources, as did the older partially paid save. A physical Fold 7 test is open.
