# World 1 snow truck and garage art

The installed truck and garage use two Meshy image-to-3D results made from the owner's selected GitHub render crops. The fitted truck retains the generated cab, bonnet, front fenders and bed. The garage retains the generated timber, stone foundations and roof geometry. The models retain the source Meshy base-color textures byte for byte. A fitted material adds cobalt panel seams, rounded snow boundaries and a light timber lift while preserving the original Meshy texture, geometry and pivots.

The functional tires, horizontal blades and low blade mount use separate fitted pieces, with the generated truck's static tires, blades and loaded display cut away. Actual inventory supplies visible typed examples above the bed. The garage's fitted interior, floor marker, sign and 12-slat shutter leave a clear bay. An inferred static shutter was removed from each end of the donor. The camp-side rear is physically open and native cutaway visibility uses the separate roof group.

[Native proof, exact Meshy task IDs and embedded texture hashes](Model-proof.json) bind 14 tests to the game assets. The art probe exercises independent counter-rotation and wheel rotation, separation of the garage shutter and roof, and repeatable door travel. The large mixed-load example renders at most twelve models with an exact decimal quantity. The matched and older warehouse control routes, together with on-actor driving and destruction evidence, are in the main playtest reports.

The neutral images were rendered using Godot 4.7.2 Compatibility. The reconstruction procedure uses the physical pivot parts authored by [the Blender script](author_snow_assets.py), [the fitting script](fit_meshy_assemblies.py), the raw task models and the [fit coordinates](mesh-fit.json). Use [the final UV paint script](smooth_garage_roof.py) on the fitted garage GLB to reproduce the delivered finish. Use a separate working project to regenerate the pivot parts. Set `HAVENLINE_SNOW_TRUCK_ART` to a folder containing the raw Meshy models, the pivot GLBs as `prototype-truck.glb` and `prototype-garage.glb`, and the fit coordinates. Run [the native proof](check_art.gd) with the actual game's project as `--path`. Pass `-- --show` and set `HAVENLINE_TRUCK_ART_REVIEW` to an existing capture folder for the studio output.
