The branch starts with Alfred’s recovered field work and uses a separate World One save profile. [Get the build or run from Git](Build/README.md) · [Source manifest](Build/Reviewed-files.json)

Alfred can follow the opening from harvesting the first tree through the furnace, two camp expansions, three separate storage purchases, eastern watchtower and extra axes. The landscape run spent 18 wood, 8 stone and 2 meat across the eight purchases, traveled 100.78 m from the origin and returned. All 15,603 sampled physics ticks balanced the three material inventories. The gate checks include the south and east passages in both directions.
