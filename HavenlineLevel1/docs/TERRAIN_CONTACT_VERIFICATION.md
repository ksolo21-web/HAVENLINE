# Opt-in terrain contact checkpoint

An alternate scene pairs one visual mesh with one static ground collider from the same accepted terrain geometry. It has no default boot hook and uses an isolated physics layer. Godot headless passed 95 bundled and 35 independent tests plus 7 existing ordinary wood tests. The independent translated/rotated scene had a maximum 0.027 mm ray/terrain height difference. This does not prove pixels, actor locomotion, interactive water/fishing, device performance or a release.
