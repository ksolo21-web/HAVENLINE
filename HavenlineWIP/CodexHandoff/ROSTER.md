# Havenline dashboard avatar roster

Codex: [roster.json](roster.json) is the roster to build from. Create **15 distinct humanoids: Alfred plus 14 bot roles**. These are durable roles, including two independent critics and two repair roles. They are not 15 workers running at once. Use the stable `id` for each avatar. A temporary specialist's work can appear under its owning role without inventing a new permanent avatar.

Pair the roster with [the status feed](status.json) for confirmed project assignments and work state. If there is no direct evidence of a role's current activity, leave the avatar static or label it “No current update.” If the feed is stale or unreachable, say so and do not mark a role as working. The optional animation hints represent real categories of work; they are not a live stream of worker screens, an indication that a task is running, or instructions to change the game.

Use separate character silhouettes, tools, or workstations to tell avatars apart. Do not animate text labels. Roster additions and project work are distinct from dashboard appearance changes and from permission to start, stop, or control anything.
