# Docked counter: native centerline capture extension

Extends the existing side-fit render observer without changing the test fixture, camera, collider, gameplay, saves, or asset. After earning the camp through the normal opening, the actor walks to the intended center service stance, then presses directly into the counter until its existing collider stops the actor. The real game camera captures stance and hard stop on both sides. Foot positions are counter-local. The original 12 planned shots are retained.

The worktop projects beyond the narrow barrier. Worktop points near counter-local X=0, Y=0.954m, Z=±0.445m are inside the player's capsule footprint at hard stop. This is a physical proxy overlap, not yet evidence that the visible body clips the worktop. In the native captures, check both the normal standing posture and the hard stop, including the worktop edge and any visible body penetration. If an ordinary approach clips, stage a local blocker or adjusted approved approach and replay both gates and all six blocked center/seam directions before visual review.

Run from this directory with the same three arguments as the original launcher (repo, existing empty output, shared renderer lock). It expects 16 native images and four position records. No display is available in the current environment; no native PNG was captured. The included movement log is from an isolated hydrated Godot 4.7.2 project using explicit `HVN_DOCKED_ROUTE_ONLY=1` and `--headless`. That mode skips all image reads and prints each skipped stage. It does not count as a graphical, device, or hybrid collision-plus-appearance pass.
