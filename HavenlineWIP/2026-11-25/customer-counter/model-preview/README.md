See [the detached side-fit source](https://github.com/ksolo21-web/HAVENLINE/commit/f2399aa25b969fe379df6387b9a4f66c4cc553af).

These are offline Blender renders, not gameplay, artistic approval, or proof of customer interactions. The flat flanks are the current test wall. No change to the playable scene. Reproduce using `blender -b --python render.py -- /path/to/side-fit-assets /path/to/output-directory`; run `layout.py` next to the three output PNG files to build the sheet.
