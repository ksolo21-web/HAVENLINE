# V4 rope X readability — no admitted candidate

This geometry-only study keeps exact prior V3 timber, draped caps and art provenance. No renderer, game/project files, shader, purchase or GitHub touched. No new variant is offered for a live run. Current 9.1 camera test remains a hold, not ownership or art approval, and neither V3 nor these diagnostics are the user's exact 18595 render.

The bounded uniform +42% signed Y scale shared by both complete ropes within each band (exact X/Z, inverse-transpose normals) increased mean upper-quartile visible branch center separation at stock 720px height from 4.23 to 5.94px. It preserved 24 exact crossover triangle identities per X, all 40 original rope/wood sectors, same masks of the 16 section bearings, exact measured crossover gap at -0.6mm, and introduced no strict noncorresponding rope, snow or neighboring board crossings. It did increase interior seating at 143 corresponding vertex/midpoint/barycenter samples, up to 1.302mm against the already embedded unchanged timber. Do not pass this as preserved clearance: same support sector does not prove same depth.

Two alternatives were explored only as rejection controls within this isolated geometry stage. Moving just the uncontacted rings kept sampled seats exact but kinked the formed rope: 133.73-degree worst path turn against 44.09 degrees in the predecessor, with only ~0.77px greater sampled separation. A smooth neighbor-weighted solve anchoring all original rope-to-wood and rope-to-rope intersecting triangles kept every strict original intersection pair and segment length identical and found no new interior samples, but distorted section planarity by up to 6.866mm (diametrical centers split 11.49mm), turned up to 74.87 degrees, and only gained ~0.89px under the same panel-only projection. That narrower rescue would likely read as bends, not continuous hemp. All scratch OBJs were removed after measurement; no staged material or authoritative scene. These are finite counterexamples, not a universal impossibility verdict.

Recipes: transform.py reproduces uniform affine trial; masked_trial.py is a deliberately unqualified geometry-only rejection control; anchored.py reproduces the contact-fixed control (shared positive Y factors and smooth recomputed normals). All accept exact V3 OBJ then own output path. For each trial use project.py to report depth-tested material coverage with stock camera scales, three physical pixel phases and reciprocal branch separation; sample_embed.py to compare sampled support, and measure_contacts.py with optional --exact-pairs for the contact-fixed control. summarize.py reads the script's expected temporary filenames and the recorded detailed evidence. None of the analytical samples is actual gameplay raster, lighting or artist critique.
