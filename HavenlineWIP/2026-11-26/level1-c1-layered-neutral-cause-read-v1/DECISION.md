## Design decision, not permission for another build

An independent boot/cuff construction can enforce zero strict neutral intersections **if** it first admits a shared embedded 3D collar chart rather than building two unrelated lofts: fix real sole/upper interfaces and hardware carriers; define one conforming finite tetrahedral collar envelope; certify positive signed Jacobians and disjoint nonincident tetrahedra (and exact incident face/corner continuity); require all fixed lower/upper rails to be distinct boundaries in the parametrized chart and disjoint from preserved source. Author boot exterior, interior liner, cuff exterior/liner and intended material returns as nonintersecting ordered surfaces within that same certified chart, separated by positive signed clearance where there is no designed joined seam. Generate artwork only from those included geometric sets, with consistent shared triangulation and real physically directed returns, then independently enumerate all resulting neutral strict crossings (must be zero) before taking any authored skin question seriously. For a monotone slab chart, a candidate rail that dips through the overlap fails admission; a nonmonotone source needs a more general certified chart, not a last-run zipper. No such admissible chart on these protected exact rails or real liner gap is currently established, so this note does not recommend another parameter sweep or request authority for a second prototype.
