# Runnable paid-pine under/over balance regression
Run python regression.py. This is an offline transcription pinned to the exact original GDScript ledger and save validators, not engine execution or a new save/receiver. The synthetic paid-control envelope reproduces the earlier actual 326-byte checkpoint SHA 832e3f09… in memory, and cold model accepts it. Six typed/impossible balance variants fail exact restore/precommit decision and cold decode even with valid outer hashes; existing snapshot bytes/state are retained by the modeled rejection paths. A corrupt old primary is also not replaced, and missing/hash-invalid controls are distinct.

A future approved closed storage slice can check carry + durable credited storage = lifetime pine units after original paid startup, but the arithmetic here cannot authorize, debit, simulate or persist a receiver. Native transaction stages, path custody and any real user saves are out of scope and untested. Adjacent gate stages and production were not modified.
