# Gate settles shut, standalone foley sketch
An original procedural mono one-shot in which a short muted metal catch is followed by a soft timber body and small dry friction tail. Designed for the physical end of a close, not switch press, moving gate, obstruction, reopen, purchase or restore. No samples, source assets, game player, bus, external service, background wind, mixing, renderer or credits. Concept intent only: no audition, in-context masking or audible quality review performed.

Regenerate: python synth.py gate-settle-draft.wav. Verify: python verify.py (local ffprobe/ffmpeg). Output 48 kHz 16-bit mono, .32 seconds with quiet edges/headroom. Keep stand-alone; no T54 changes or use as a built cue. Hearing it and evaluating its level under wind are still separate gates.
