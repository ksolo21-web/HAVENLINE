# Exact SW shared-post socket graft: geometry built, rejected
This is an actual detached indexed mesh and verification witness, not an admitted/game-ready prototype. Two rooted owner-style donors use the sealed exact SW baseline; removed only duplicate terminal post/cap from each. Preserved every one of the 14 remaining rooted post/cap groups (5,040 faces). Kept original opposite ends and real signed section-specific graft rings, reused the single 440-face corner timber/cap only. Ropes use original six-sided section geometry through the replacement loops rather than increasing detail gratuitously. Run gate and counter are not in this fixture.
   
The four actual rail sockets all contact the same shared timber; the cap rings lie at least 31.33–35.23 mm inside its conservative radial envelope, and the West lower cap is now above the shared root in this screen. All output groups edge-closed and directed winding consistent. The current 23,656 triangles are 152 below two unchanged donors. Warm and cream loops both remain closed and enter the shared timber; no native visuals assessed. OBJ exports neutral geometry without paid texture or material, so it cannot certify an art match.
   
Two versions tested in this owned folder. First linear four-station loop (22,024 tris) eliminated strict cross-arm intersections but generated folded/self-crossing connector triangles up to 13.59 mm. Current rigid donor ring treatment mostly fixes that; however four same-rope strict positive self-crossings remain on West lower (up to 1.883 mm), and there are two cross-arm contact categories shown in the manifest. Critically, the exact West lower segment still goes into the actual indexed terrain: −138.73mm minimum sampled rail vertex and −138.83mm rope even after raising the buried cap. The minimum is at/near the inner graft transition, not proof the terrain penetrates all parts. A hidden cap and closed topology cannot excuse those checks. Do not launch or mount.
   
One next physically different repair would need a grade-aware West facing lower route with source terrain bounds at the whole splice, retain the same exact root/opposite end and avoid floating cut facades; the current raw corner attachment under the floor is not an acceptable collision/appearance shortcut. Joint positives confined to designated contacts and no self/cross-arm pairs must be independently replayed before any native step.
   
Run `python graft.py` with NumPy and adjacent exact sources. `trial-linear.py` is the first rejected method; it writes the result JSON and should only be used in a work copy. No engine, spend, raw paid texture, game edits, or publication.
