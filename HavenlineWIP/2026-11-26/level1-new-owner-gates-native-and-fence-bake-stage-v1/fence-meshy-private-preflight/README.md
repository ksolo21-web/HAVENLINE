# Private source-only Meshy front native preflight
**Not run, not a critic pass, and not an integrated visual replacement.** Never publish or serve the Meshy texture data from this package. This is a separate one-module branchless test against the successful detached manual owner-panel route. All inherited game authority, camera and lighting, physical collider source, exact stock transform, 11 neighboring old-art controls, opposing gate/snow/other assets stay the same. Only two inherited panel/test guards, the exact front+rear mesh resource, and its explicit local atlas/UV guard changed. 
   
The runtime requires exact model identity, ten material surfaces, original plain color rows, the five exact 768x384 imported local albedo maps, finite XY-to-UV mapping with the expected PNG-origin conversion, and exact per-face triangle census with no other texture, emission, or surface override. Failed assumptions must reject; do not bypass a texture/UV check if importer behavior is different. Review crops derive from the stock post-draw bounds and contain A on left, Meshy B on right; numeric controls preserve native route snapshots, payment/gates, and cold-save receipt. Outside-ROI differences are recorded and need investigation, not attributed to Meshy automatically.
   
Independent source scope permits only this narrow diagnostic: no direct donor ghost found but some material triangles reach negative local Z (397 front-assigned faces, not a rear-facing guarantee), warm and cream use identical sampled RGB, and diagonal projected angle/coverage have expected degeneracies. Quarter-view artifacts and rope readability need independent reviewer in normal game camera; do not infer rear or installed result. Stage once with `bash stage.sh`; root alone can run `bash tty_capture.sh --sole-renderer-lease PATH_TO_SHARED_LOCK` when renderer becomes free.
