# Detached paid wood validating seam
Python reusable pure validator, synthesizes no receiver rights, reads/writes no actual save, never actuates a deposit or chooses a receiver. It checks a closed wood-only custody scope by immutable external evidence, not by inferring earned units from current stock. Strict original exact hearth authority, signed original cap, distinct evidence tickets and earned unit IDs, valid typed 1 wood rows, independently provided evidence set equality and subtraction conservation avoid duplicate debit/credit or arithmetic overflow. No accepted external authority means no credits. The test supplies offline-only tuples; there is no sanctioned mapping from real receiver records yet.

Explicit bridge accepts only the exact already archived 326-byte synthetic fixture digest under an explicit test-only intent, with zero credited units and exact original authority. Old snapshots/envelopes are refused by the new validator if not explicitly bridged. It is not save-format migration, v3 project schema, blanket old-data support, or approved storage; old files remain unchanged.
