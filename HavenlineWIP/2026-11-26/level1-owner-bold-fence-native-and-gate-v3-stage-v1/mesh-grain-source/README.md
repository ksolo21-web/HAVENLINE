# Private, one-panel Bold V3 + actual Meshy timber
This candidate preserves exact owner-reference Bold V3 positions, normals and triangle winding; both real rope colors, all rail/snow shading and the entire authored rear remain exact. The only material replacement is 168 front timber faces, 21 per log. Every one of their vertices has Z >= +8.129616 mm. Each physical post maps to its own isolated donor strip with seam falloff; only classified warm amber wood is admitted and hidden rail/rope bands are interpolated from clean wood on that same post. Donor rope, rail, snow, background and topology stay out. The protected collider and scene are not in scope.
   
The +33° offline A/B has 54,422 changed timber pixels; +147° and exact rear both have zero RGB change. No affected pixel belongs to rope, rail or snow in any of these views. Genuine RGB is copied at the core of each tile; bevel seams return to the quantized original material color. A native importer might show seam/color-space differences, so use one isolated geometry-matched same-camera preview and independent critic before any claim. The front material alone does not cure dark native lighting on snow; this intentionally changes no snow, lighting or rig.
   
Run `python bake_bold.py --fresh` from here with original adjacent input packages, NumPy, SciPy and Pillow. The ordinary path uses the exact offline donor cache. The private derived atlas, candidate and evidence are not cleared for public redistribution. No credits, engine, GitHub, scene modification or critic signoff occurred.
