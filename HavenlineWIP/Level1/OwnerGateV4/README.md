# Owner-reference Level 1 gate V4 source (WIP)

Procedural source for the two leaves and two threshold posts. The builder’s authored geometry and plain material palette are included; no reference image or Meshy model/texture is included. With Python 3 and NumPy, run `python build.py` and compare stdout with `build-result.json`. A clean local build reproduced all four OBJ files and the material file byte-for-byte. This does not install the assets.

V4 changes only the front cross-braces relative to V3: broader shoulders and slightly deeper rounded sections. Independent static review confirmed unchanged 44 mm closed seam and clearance to matching stationary posts. Native visual and game review pending. Do not replace the playable build with this WIP.
